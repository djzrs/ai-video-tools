小说转标准剧本

把文字变成「可拍摄」的指令
核心是 Show don't Tell —— 能被镜头拍到的，才算数

小说擅长写「心里怎么想」，但摄影机拍不到内心独白。这一步的关键，是把抽象的心理描写改写成能被镜头拍到的动作、表情、道具和场面。

每个场景必须明确五件事

🧑谁
📍在哪
🏃做什么动作
💬说什么台词
🎭什么情绪

改写示例

小说原文（Tell）标准剧本（Show）
他内心十分紧张，害怕被揭穿。 他攥紧的拳头微微发抖，喉结滚动了一下，避开对方的目光，把文件往身后藏。
她其实早就原谅了他。 她接过他递来的伞，指尖在伞柄上停了半秒，最终没有推开。雨里，两人共一把伞，距离很近。
🏢 腾讯云山海团队实践
把创作动作从「分散在不同人员、文档、聊天记录」变为「为每个生产动作设置明确的入口、标准对齐的输入输出」，是稳定交付的前提。

剧本转分镜表

把剧本拆解成可执行的镜头清单
标准分镜表：让每一镜都有据可依

标准分镜表七要素

🔢镜号
🔭景别
🎥运镜
🖼️画面描述
🔊音效推荐
🗣️旁白 / 台词
⏱️时长

节奏控制

  • 每集控制在 10-13 镜，保证信息密度与观看节奏的平衡
  • 每镜不超过 5 秒，适配短视频的注意力窗口

💡 实践要点
分镜表是整个流程的「施工图纸」——后续资产提取、首帧生成、视频合成全部以它为准，值得在这里多花时间。分镜表也是最不容易乱的对齐容器：出图、配音、装配全部按镜号对齐。

提取资产（角色 / 场景 / 道具）

从剧本中系统化沉淀可复用素材
三类资产，各有各的标准配置

通读分镜表，把全片需要的视觉元素系统化提取为三类资产，避免每镜临时生成导致的风格漂移：

🧑 角色资产

  • 定妆照
  • 三视图（正面 / 侧面 / 背面）
  • 面部特写
  • 表情变体

🏙️ 场景资产

  • 主设定图
  • 多角度变体（日景 / 夜景 / 氛围变体）

🎒 道具资产

  • 单件道具参考图
  • 场景中道具摆放参考
💡 为什么先提资产
先提资产再生成，才能把「跨镜复用」变成可能——同一张脸、同一个场景，在不同镜头里保持一致。

📋 可复制提示词模板

从剧本中系统化提取三类资产，生成可直接用于图像生成平台的「视觉 DNA」指令。把【】里的内容替换成你自己的素材，即可直接粘贴使用：

请从以下剧本中提取全部视觉资产，输出三类清单：

【粘贴剧本】

一、角色资产
- 角色名｜性别｜年龄｜脸型五官｜发型发色｜服装｜标志物（痣/眼镜/耳环等）
- 每个角色的外貌锚点（每镜原样粘贴的固定描述句）

二、场景资产
- 场景名｜时间｜光线方向｜色温｜主色调｜固定道具摆放

三、道具资产
- 道具名｜外观描述｜在哪些场次出现

生成资产库并锁定一致性

全流程最容易翻车的一步
一致性靠机制，不靠「提示词写得好」
⚠️ 高危环节
这是最容易翻车的一步——角色「换镜即换脸」是 AI 短剧最常见的废片原因。

专业做法

  • 先建多角度角色表，锁定面孔后，再按场景分配服装
  • Kling 的 Element Library：支持上传多角度参考图，AI 会记住角色、道具和场景，一次创建后跨镜头复用

具体流程

生成母版图定长相
→
资产图分场景按场景分配
→
换装只动衣服面孔不动
→
人眼终选写入档案

连续性锁（Consistency Lock）

把需要跨镜保持的造型，写成一条能原样贴进提示词的短语（连续性锁）；每一镜写完关键帧后，说明依据了哪些条目——漏了会被检查脚本指出。

📋 可复制模板：角色定妆卡

定妆卡是保证角色跨镜不走样的核心：先把角色三视图锁死，后续每张图都带参考图，能省下大量返工。把【】里的内容替换成你自己的素材，即可直接粘贴使用：

Character design reference sheet, same character shown in 4 views
arranged left to right (front, 3/4 left, side, back).

Character: 【角色名】
Identity: 【年龄】岁【国籍/人种】【性别】，【脸型】，【眼睛描述】，【发型发色】，【肤色】，【标志物】
Outfit: 【上衣颜色+材质+款式】, 【下装】, 【鞋子】, 【配饰】
Expression: 【基础表情气质】
Background: white neutral background, flat studio lighting
Layout: 4 views in a row, readable labels below each view
Consistent facial features, outfit, and proportions across all views.
No view merging, no feature drift, no background pollution.
💡 一句话总结
一致性不是「写得细」，而是把稳定要素固化成可复用、可校验的资产。

生成首帧（锚点帧）

批量生成前的「定稿」环节
构图、光线、服装全部确定后，再继续

在批量生成前，先为目标场景生成一张干净的、锁定的锚点帧——最终构图、最终光线、最终服装全部确定后再继续，避免带着不确定性进入视频生成。

元素绑定

  • Kling 3.0 在首帧 / 首尾帧生成中，支持绑定最多 3 个元素
  • 锁定核心特征，防止换镜时主体变形
锚定对象锁定内容
主角面孔 + 当集服装
核心道具外形 + 关键细节
场景空间结构 + 光线氛围

📋 可复制模板（万相 3.0 公式）

把【】里的内容替换成你自己的素材，即可直接粘贴使用：

【总体描述：风格+主体+场景】。
参考素材：@图片1 作为首帧画面。
分镜1（0-5秒）：【主体动作】+【场景环境】+【运动方式】+【美学控制：光线/色调/构图】。
风格/情绪：【风格关键词】。
负向清单：文字水印，面部畸变，肢体错位，背景闪烁。
💡 为什么值得单独一步
首帧阶段改一张图，比视频生成后返工便宜得多。锚点帧确认无误，再进入图生视频。
🎞️

图生视频（首帧 / 首尾帧）

让锚定帧「动起来」
有明确结束姿态时，首帧 + 尾帧比只给首帧可控得多

把锚点帧作为首帧图，写运动提示词描述从 A 帧到 B 帧的运动、运镜和情绪。

关键原则

  • 首帧 + 尾帧同时给：如果有明确的结束姿态，双帧约束比只给首帧自由发展可控得多
  • 运动提示词聚焦「怎么动」：运动路径、运镜方式、节奏与情绪变化

万相 3.0 提示词公式

总体描述 + 参考素材引用 + 分镜（起止秒） + 台词 + 音效 / BGM + 风格 / 情绪 + 负向清单

📋 可复制模板（运动控制）

运动提示词的关键是绑定参照物——不写「挥手」，写「右手抬起至与左肩齐平」。即梦平台需加「静止上半身」防关节错位，可灵需加「以 24fps 恒定输出」防 AI 补帧。把【】里的内容替换成你自己的素材，即可直接粘贴使用：

@图片1 作为首帧。

主体：【角色名，粘贴角色卡片原文】
动作：【具体动作，绑定参照物。示例：右手抬起至与左肩齐平，指尖距耳垂15厘米】
镜头：【固定机位 / 缓慢横移 / 匀速推进5米】
时长：5秒
风格：【画风关键词】
约束：面部清晰，手部静止，无插值，以24fps恒定输出
负向：肢体畸变，面部漂移，背景跳变，文字出现
💡 负向清单别省略
「负向清单」用来排除变形、模糊、多余肢体等常见缺陷，是出片率的隐形保障。

🚀 使用顺序建议：先锁资产，再跑分镜
先把第 1-3 步跑完（小说 → 剧本 → 分镜表 → 资产清单），然后执行第 4 步生成角色定妆卡，确认形象锁定后，再用第 5 步生成所有首帧图，最后进入第 6 步批量图生视频和第 7 步剪辑。确认闸门不能省：任何图片、视频、配音任务，先在文件里看到这批准确的内容和参数，明确确认后才调用外部接口花钱。
